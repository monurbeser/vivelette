# Vivellette Dress Up

Vivellette Dress Up is a polished 2D, iPad-first children's fashion doll dress-up game built in Godot.

## Godot Version

Use Godot `4.7.x`. The project was validated with Godot `4.7.2`.

## Launch Locally

1. Open Godot 4.7.x.
2. Import or open this folder as a Godot project.
3. Press Play to run the main scene.

From this machine, the local Godot executable can also run the project with:

```sh
/Users/mehmetonurbeser/Downloads/Godot.app/Contents/MacOS/Godot --path /Users/mehmetonurbeser/vivellette-dress-up
```
